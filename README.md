# XYZ Klipper Tool

XYZ Klipper Tool is a new, evidence-driven project for calibrating interchangeable Klipper toolheads:

- camera-based automatic X/Y offset measurement;
- selectable Z measurement through a physical switch or Cartographer Touch;
- command-taught and persisted measurement stations instead of fixed machine coordinates;
- report-only measurements by default, with a separate reviewed apply transaction;
- adapters for different toolchanger implementations and future hardware.

This repository is intentionally bootstrapped with governance, evidence, and an implementation prompt before production code. It is **not yet safe to install on a printer**.
